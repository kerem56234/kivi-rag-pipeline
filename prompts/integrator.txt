The integrator has the task to communicate with the different units of the pipeline. those are: the user, the retriever, the embedding model and the generating model 

user_prompt
   ↓
embed_and_retrieve(user_prompt, retrieval_view)
   ↓
embedding_model.embed(user_prompt)
   ↓
retriever.retrieve(
    search_vector=embedded_prompt,
    relation=retrieval_view,
    query_text=user_prompt
)
   ↓
form_context(retrieved_results)
   ↓
if no retrieved_results:
    ask user whether to try another search query
else:
    call_generator(context, user_prompt)
   ↓
if generator returns INSUFFICIENT_CONTEXT:
    ask user whether to try another search query
else:
    render_answer(generated_answer, retrieved_sources)
